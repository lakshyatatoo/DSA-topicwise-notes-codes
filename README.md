# DSA Handbook

A collection of Data Structures and Algorithms problems, implementations, and solutions organized topic-wise.

## Contents

- Basics
- Hashing
- Basic Maths
- Sorting
- Arrays
- Binary Search
- Strings
- Linked List
- Recursion & Backtracking
- Bit Manipulation
- Stack & Queue
- Sliding Window & Two Pointers
- Binary Trees
- Binary Search Trees
- Graphs

## Purpose

This repository serves as a centralised place to store and organise DSA practice, multiple approaches to problems, and reusable implementations for interview preparation and competitive programming.

## Source

The learning path and topic organisation in this repository are primarily based on the DSA roadmap and educational content provided by **Striver  through **Take U Forward**. The code in this repository represents implementations, practice solutions, and notes while following the roadmap.

## Notes

The repository currently focuses on code implementations and problem solutions. Explanations, complexity analysis, and detailed notes may be added over time.
